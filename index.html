♡ Sobre o projeto ♡

Este projeto foi desenvolvido para demonstrar a importância da segurança digital por meio da criptografia e das funções hash.

🔒

Criptografia

Protege mensagens usando uma chave secreta para manter os dados seguros.

🛡️

Hash SHA-256

Cria um resumo digital que ajuda a verificar a integridade das informações.

🌷 O que aprendemos?

A criptografia protege a confidencialidade das mensagens, enquanto o hash permite verificar se uma informação foi modificada.
